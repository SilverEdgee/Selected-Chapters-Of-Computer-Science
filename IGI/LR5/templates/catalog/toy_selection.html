Какие виды input показаны

type="text"
Обычная строка текста.
type="password"
Скрывает введённые символы.
type="email"
Проверяет общий формат электронной почты.
type="tel"
Поле для телефона; точную проверку задаёт pattern.
type="url"
Ожидает адрес сайта.
type="search"
Строка поискового запроса.
type="number"
Число с ограничениями min, max и step.
type="range"
Ползунок для выбора значения из диапазона.
date, time, month, week
Выбор даты, времени, месяца и недели.
type="color"
Открывает выбор цвета.
type="file"
Открывает выбор файлов.
type="radio"
Позволяет выбрать один вариант с одинаковым name.
type="checkbox"
Независимый флажок, который можно включить или выключить.
type="hidden"
Не отображается, но отправляет служебное значение вместе с формой.

Что означают атрибуты

type
Определяет вид и поведение поля или кнопки.
id
Уникальное имя элемента, на которое ссылается label for.
name
Имя параметра, под которым значение отправляется серверу.
value
Начальное или отправляемое значение; у кнопки это надпись.
placeholder
Краткий пример внутри пустого поля; не заменяет label.
required
Не разрешает обычную отправку, пока поле не заполнено.
minlength, maxlength
Ограничивают длину текста.
min, max, step
Задают минимальное, максимальное значение и шаг числа или ползунка.
pattern
Задаёт шаблон допустимого текста в виде регулярного выражения.
checked
Предварительно выбирает radio или checkbox.
readonly
Запрещает редактирование, но значение поля отправляется.
disabled
Полностью отключает элемент; его значение не отправляется.
accept
Подсказывает допустимые типы файлов.
multiple
Разрешает выбрать несколько файлов.
autocomplete
Подсказывает браузеру назначение данных для автозаполнения.
formnovalidate
У кнопки submit отключает встроенную проверку полей для этой отправки.
formaction
У кнопки submit переопределяет адрес отправки родительской формы.
formmethod
У кнопки submit переопределяет метод отправки, например get или post.
formenctype
Задаёт способ кодирования данных; multipart/form-data нужен для передачи файлов.
formtarget
Определяет, где открыть ответ; _self означает текущую вкладку.
src, alt, width, height
Для type="image" задают картинку, её текстовую замену и размеры.
title
Добавляет дополнительную подсказку при наведении.
